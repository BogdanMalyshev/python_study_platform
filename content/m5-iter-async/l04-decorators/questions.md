# Ключові питання уроку m5-l04 "Декоратори функцій і класів, декоратори з параметрами"

Урок готовий, коли на кожне питання є відповідь з кодом і виводом.

- [x] Декоратор це функція, що приймає функцію і повертає функцію; `@deco` дорівнює `f = deco(f)` і виконується в момент визначення. Порівняти з HOC у React і з TS-декораторами (стандарт 2023 і legacy experimentalDecorators).
- [x] Класичний шаблон: `wrapper(*args, **kwargs)`, `functools.wraps`, повернення результату; що ламається без `wraps` (`__name__`, docstring, `inspect.signature`, pytest-параметризація).
- [x] Декоратори з параметрами: фабрика декораторів (три рівні вкладеності), `@retry(times=3)`, і спосіб зробити дужки необов'язковими одним прикладом.
- [x] Порядок застосування кількох декораторів (знизу вгору) і чому це важливо для `@property`+`@cache` або `@staticmethod`+власний.
- [x] Декоратор як клас з `__call__` (посилання на m4-l02): коли клас зручніший (стан, лічильник викликів), `functools.update_wrapper`.
- [x] Декоратори методів: `self` проходить через `*args`; декоратор, що читає атрибути екземпляра; дескрипторна природа методів одним реченням (посилання на m4-l03).
- [x] Декоратори класів: `@dataclass` як приклад (посилання на m2-l05), власний декоратор-реєстратор `@register("input")`, що кладе клас у словник, і чому це альтернатива `__init_subclass__` (посилання на m4-l04).
- [x] Асинхронні функції: декоратор має повернути `async def wrapper` і `await`; визначення через `inspect.iscoroutinefunction`; типова помилка, коли синхронний wrapper обгортає корутину і повертає її без await (посилання на m5-l05).
- [x] Типізація декораторів: `ParamSpec` і `TypeVar` для збереження сигнатури, `Callable[P, R]`, чому без цього mypy втрачає типи (посилання на m2-l06).
- [x] Вбудовані й поширені: `@staticmethod`, `@classmethod`, `@property`, `@cache`, `@contextmanager`, `@singledispatch`, `@pytest.fixture`, `@app.get("/")` з FastAPI одним реченням (посилання на m7-l01).
- [x] Для капстоуну: `@timed` для етапів пайплайну з логуванням (посилання на m5-l09), `@retry(times, delay)` для публікації з експоненційною затримкою, `@register(ElementType.INPUT)` для рендерерів.
- [x] Які JS-звички тут шкодять: TS-декоратори лише на класах і членах (тут і на функціях), очікування метаданих reflect-metadata, HOC з пропсами, `fn.bind` всередині wrapper, забутий `return wrapper(...)`.
