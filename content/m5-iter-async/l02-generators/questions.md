# Ключові питання уроку m5-l02 "Генератори, yield, yield from, ліниві конвеєри"

Урок готовий, коли на кожне питання є відповідь з кодом і виводом.

- [x] `yield` перетворює функцію на генераторну: виклик повертає об'єкт-генератор, тіло не виконується до першого `next`; `StopIteration` при `return`; стан локальних змінних зберігається між `yield`. Порівняти з `function*` один в один і показати, що це те саме.
- [x] Генератор як найпростіший ітератор: переписати `Countdown` з m5-l01 у три рядки; `__iter__` класу як генератор.
- [x] Генераторні вирази `(x for x in ...)` проти list comprehension (посилання на m1-l10): пам'ять на мільйон елементів через `tracemalloc` або `sys.getsizeof`, одноразовість, передача у `sum`/`any`/`join`.
- [x] Ліниві конвеєри: ланцюжок генераторів `read_lines → parse → filter → take`, де кожен елемент проходить весь ланцюжок до того, як береться наступний; `itertools.islice` для "перших n" без читання всього; порядок виконання з print-ами.
- [x] `yield from`: делегування під-генератору, сплющення рекурсивного обходу дерева, і чим відрізняється від `for x in sub: yield x` (передача `send` і значення `return`).
- [x] `send`, `throw`, `close` і генератор як корутина: один приклад з `send`, зв'язок з `async def` (посилання на m5-l05) без глибини; `return value` у генераторі і де його забрати (`StopIteration.value`, `yield from`).
- [x] Очищення: `try/finally` навколо `yield`, `GeneratorExit` при `close()` або збиранні сміття; чому генератор-читач файлу має використовувати `with` усередині.
- [x] Пастки: генератор, який випадково споживають двічі; `return` з генератора замість `yield` (порожній генератор); забутий `list()` при повторному використанні; генератор у `len`/індексі.
- [x] Типізація: `Iterator[str]` для простого випадку, `Generator[Y, S, R]` для send/return, `Iterable[str]` як тип параметра (посилання на m2-l06).
- [x] Для капстоуну: генератор `walk(element)` (обхід дерева через `yield from`), конвеєр `configs → validate → render → publish` як ланцюжок генераторів, який воркер споживає порціями; прообраз асинхронної версії в m5-l05.
- [x] Які JS-звички тут шкодять: `function*` вважають екзотикою (у Python генератори всюди), `Array.from(gen)`, очікування, що `yield` без `*` делегує масив, `return` у генераторі як `done: true, value` (тут значення майже ніколи не читають напряму).
