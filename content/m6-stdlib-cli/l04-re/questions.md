# Ключові питання уроку m6-l04 "re проти JS RegExp"

Урок готовий, коли на кожне питання є відповідь з кодом і виводом. Учень знає регулярні вирази з JS; урок про відмінності API і синтаксису.

- [x] Модуль `re`: `search` проти `match` (прив'язка до початку) проти `fullmatch`, `findall`, `finditer`, `sub`, `split`; об'єкт `Match` з `group`, `groups`, `groupdict`, `span`. Порівняти з `str.match`, `matchAll`, `replace`, `test`.
- [x] Raw-рядки `r"\d+"` і чому без `r` ламається (`\b`, `\`); компіляція `re.compile` і кеш; коли компілювати явно.
- [x] Прапорці: `re.I`, `re.M`, `re.S` (DOTALL), `re.X` (verbose з коментарями, головна перевага над JS), `re.A`; відповідності `i`, `m`, `s`, і відсутність `g` (глобальність задає метод).
- [x] Іменовані групи `(?P<name>...)` проти `(?<name>...)` у JS, посилання `(?P=name)`, `\g<name>` у заміні, функція як заміна в `sub` (аналог колбека в `replace`).
- [x] Синтаксичні відмінності: lookbehind довільної довжини немає (лише фіксована), `\Z` замість `$` для кінця рядка без переносу, `[[:alpha:]]` немає, Unicode-класи `\w` за замовчуванням Unicode (на відміну від JS без `u`), `\d` ловить не лише ASCII-цифри. Пакет `regex` одним реченням.
- [x] Жадібність, ліниві квантифікатори, `re.sub` з `count`, `re.split` з групами, що зберігають роздільник; `re.escape`.
- [x] Продуктивність і катастрофічний backtracking на прикладі; таймаутів у `re` немає; `re.finditer` як лінивий.
- [x] Коли не regex: `str.startswith`, `in`, `partition`, `split` (посилання на m1-l04), парсери для структурованих даних (JSON, HTML через парсер, не regex).
- [x] Типізація: `re.Pattern[str]`, `re.Match[str] | None` і narrowing через walrus (посилання на m1-l05).
- [x] Для капстоуну: валідація `name` елемента (`^[a-z][a-z0-9_]*$`), парсинг плейсхолдерів `{{ field }}` у текстах форми з `finditer`, нормалізація slug через `sub`.
- [x] Які JS-звички тут шкодять: літерали `/.../g`, `String.prototype.match` з `g` (тут `findall`), `replace` замінює лише перший без `g` (тут `sub` замінює всі), `lastIndex` і stateful regex, `$1` у заміні (тут `\1` або `\g<1>`).
