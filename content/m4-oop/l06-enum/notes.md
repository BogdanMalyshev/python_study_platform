# Notes: m4-l06 "Enum, StrEnum"

## Що запускалось

Інтерпретатор `.venv/bin/python` (Python 3.12.12, pydantic 2.14.1), mypy 2.4.0 з `.venv/bin/mypy`. Тимчасові скрипти в `<scratchpad>/m4-l06/`, після перевірки папку видалено.

- Кожен блок ```` ```python ```` / ```` ```python live ```` з теоретичної частини `lesson.md` вирізався скриптом, запускався окремим файлом, і його stdout (плюс останній рядок traceback для прикладів, що закінчуються винятком) порівнювався з наступним блоком ```` ```text ````. Усі збігаються. Блок з `Status("published")` / `Status["ARCHIVED"]` є продовженням першого прикладу і запускався з префіксом-оголошенням `Status`.
- Блок з `assert_never` і `describe("done")` перевірявся `.venv/bin/mypy --strict statuses.py`; вивід вставлено дослівно.
- Фрагменти в "Типові помилки" перевірені окремим скриптом з потрібними оголошеннями (`Plain.DONE == "done"`, `f"{Old.DRAFT}"`, `auto()` для `Enum`/`StrEnum`, `Status["draft"]`).
- `tasks.yaml`: для t1–t4 `solution + harness` дає рівно `expected`; `starter + harness` запускався, щоб переконатися, що стартовий код синтаксично коректний. Код з питань q1–q3 запущено, вивід збігається з `options[answer]`. Кожен id вставлено в `lesson.md` рівно один раз, порядок у yaml збігається з порядком у уроці.

## Рішення

- Обсяг: 27 абзаців теорії (з них 5 callout-ів), у межах 20–30 для короткого уроку.
- Завдання: 4 code (t1–t3 stdlib, t4 з `requires: [pydantic]`), 3 quiz. Усі `runtime: browser`, детерміновані. Проєктного завдання немає за умовою замовлення (лише браузерні завдання й запис тільки в папку уроку); капстоунні частини (`JobStatus.can_transition_to`, перехід статусу через Pydantic) зроблені як t3 і t4, а розділ "Для капстоуну" показує заміну `Literal["input"]` на `Literal[ElementType.INPUT]` у discriminated union з m2-l09.
- Таблиця переходів `JobStatus` винесена на рівень модуля: у тілі `StrEnum` словник став би членом і кинув `TypeError`. Це оформлено пасткою з кодом, бо саме так напише JS-розробник.
- Пастка `(str, Enum)`: з 3.11 `format()` повертає `Status.DRAFT`, перевірено на 3.12 (q2).
- `"draft" in Status` дає `True` (поведінка 3.12; до 3.12 перевірка не-члена кидала `TypeError` за документацією, на старших версіях не запускалось).
- Дескриптори згадані одним реченням з посиланням на m4-l03; `assert_never` і `Literal` з посиланням на m2-l06; value pattern у `match` з посиланням на m1-l05; обробник помилок FastAPI з посиланням на m7-l02.
- Відмічено як мінус: повідомлення Pydantic `union_tag_invalid` при enum-тегах показує `repr` членів, а не рядки.
