# Ключові питання уроку m0-l04 "ruff: лінтер і форматер в одному"

Урок готовий, коли на кожне питання є відповідь з командами і реальним виводом (ruff встановлений у `.venv`).

- [x] Що таке PEP 8 і чому його не треба вчити напам'ять: форматер робить відступи, пробіли, довжину рядка, лінтер ловить помилки. Історія в одне речення: flake8, black, isort, pylint, і чому ruff їх замінив (швидкість, один конфіг).
- [x] `ruff check` проти `ruff format`: що робить кожна, `--fix`, `--diff`, `--check`. Аналогія: `eslint` і `prettier`, але один бінарник і один конфіг.
- [x] Конфігурація в `pyproject.toml`: `[tool.ruff]` з `line-length`, `target-version`; `[tool.ruff.lint]` з `select`, `ignore`, `extend-select`. Що вмикається за замовчуванням (E, F) і які набори варто додати для цього курсу (`I` isort, `UP` pyupgrade, `B` bugbear, `N` naming, `SIM`, `RUF`). Показати конфіг і реальний вивід на файлі з помилками.
- [x] Прочитати повідомлення ruff: код правила, пояснення через `ruff rule F841`, `# noqa: F401` для точкового вимкнення і чому це має бути рідкістю.
- [x] Правила, які найчастіше спрацьовують у JS-розробника: E711/E712 (`== None`, `== True`), E731 (lambda у змінну), B006 (mutable default), F401 (невикористаний імпорт), F841 (невикористана змінна), N802/N806 (camelCase), UP (старий синтаксис типів). Показати кожне з реальним виводом.
- [x] Форматування: що ruff format змінює (лапки на подвійні, trailing comma, довжина рядка 88), що не змінює, `# fmt: off`. Чому не сперечаються про стиль.
- [x] Сортування імпортів (`I001`): стандартна бібліотека, сторонні, локальні; `ruff check --select I --fix`.
- [x] Інтеграція: розширення для VS Code / PyCharm, format on save, `pre-commit` (одне речення, детально в m3-l06), запуск у CI одним рядком.
- [x] Для капстоуну: налаштувати `[tool.ruff]` у `pyproject.toml` проєкту і прогнати на стартовому файлі.
- [x] Які JS-звички тут заважають: окремий `.eslintrc` з плагінами, `prettier --write` окремо, очікування, що лінтер перевіряє типи (це mypy/pyright, m2-l08), одинарні лапки як стиль.
