# Ключові питання уроку m1-l04 "Рядки: f-рядки, методи, зрізи"

Урок готовий, коли на кожне питання є відповідь з кодом і виводом.

- [x] Літерали: `'...'`, `"..."` рівнозначні, `"""..."""` багаторядкові, `r"..."` для regex і шляхів, конкатенація сусідніх літералів `"a" "b"`. Що з екрануванням і `\n`. Де різниця з JS: немає backtick, є raw-рядки.
- [x] f-рядки як template literals: `f"{x}"`, вирази всередині, `{x!r}`, `{x=}` для дебагу, формат-специфікації `{price:.2f}`, `{n:>10}`, `{n:,}`, `{dt:%Y-%m-%d}`. Вкладені лапки у 3.12. Чому `str.format` і `%` ще трапляються в чужому коді.
- [x] Індексація і зрізи: `s[0]`, `s[-1]`, `s[1:4]`, `s[::2]`, `s[::-1]`; зріз ніколи не падає за межами, індекс падає (`IndexError`). Порівняти з `slice`, `at`, `charAt`.
- [x] Незмінність: `s[0] = "x"` це `TypeError`; кожен метод повертає новий рядок. Як збирати рядок у циклі: `"".join(parts)`, а не `+=` (і чому `+=` у циклі все ж не катастрофа в CPython, але `join` ідіоматичний).
- [x] Методи, які JS-розробник шукає, і їхні імена: `split`/`join` (join на роздільнику!), `strip`/`lstrip`/`rstrip` (trim), `replace`, `find`/`index` (indexOf, але `index` кидає), `startswith`/`endswith`, `upper`/`lower`/`title`/`casefold`, `isdigit`/`isalpha`, `zfill`, `center`, `partition`, `removeprefix`/`removesuffix` (3.9+). `in` замість `includes`.
- [x] Чому `"a,b,,c".split(",")` і `"a  b".split()` поводяться по-різному (без аргументу ділить по будь-яких пробілах і прибирає порожні).
- [x] `len`, `ord`, `chr`, ітерація по символах, `enumerate` по рядку. Що таке code point і чому `len("é")` може бути 1 або 2 (NFC/NFD, одне речення).
- [x] `str` проти `bytes`: `encode`/`decode`, UTF-8 за замовчуванням, `b"..."`, чому `bytes` не склеюється зі `str`. Де це зустрінеться (файли, мережа, subprocess). Детально в m6-l01.
- [x] Порівняння й сортування рядків: лексикографічно по code point, `"Z" < "a"`, `sorted(words, key=str.lower)`, `casefold` для регістронезалежного порівняння.
- [x] Перевірка підрядка й пошук: `in`, `count`, `find` повертає `-1`, regex лише згадка з посиланням на m6-l04.
- [x] Багаторядковий текст: `textwrap.dedent`, `splitlines`, `"\n".join`. Коли `"""` у коді дає зайві відступи.
- [x] Які JS-звички тут шкодять: `str.length`, `arr.join(",")` замість `",".join(arr)`, `str.includes`, `+` для збирання у циклі, `substr`, `padStart` (є `rjust`/`zfill`), очікування, що `split` з лімітом працює як у JS (`maxsplit` інакший).
