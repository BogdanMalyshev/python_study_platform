# Ключові питання уроку m1-l01 "Відступи, імена й порядок визначень"

Урок готовий, коли на кожне питання є відповідь з кодом і виводом.

- [x] Чому відступи в Python це синтаксис, а не форматування: що саме робить інтерпретатор з відступами (INDENT/DEDENT), що станеться при змішуванні табів і пробілів, і чому стандарт 4 пробіли? Як виглядає `IndentationError` і `TabError`?
- [x] Де в Python ставиться двокрапка і що вона відкриває (блок після `if`, `for`, `def`, `class`, `with`, `try`), і чому немає фігурних дужок і крапки з комою? Як перенести довгий вираз на кілька рядків (дужки, зворотний слеш) і де JS-звичка "перенос де завгодно" ламається?
- [x] Як іменують у Python: snake_case для змінних і функцій, PascalCase для класів, UPPER_CASE для констант, `_private` і `__name_mangled`, `_` як "не використовую". Що з цього перевіряє інтерпретатор, а що лише конвенція PEP 8? Що означають і як відрізняються `_x`, `__x`, `__x__`?
- [x] Чому немає hoisting: що станеться, якщо викликати функцію до її `def`, звернутись до змінної до присвоєння (`NameError`, `UnboundLocalError`), і як це відрізняється від function declaration у JS?
- [x] Що таке "виконання модуля зверху вниз": `def` і `class` це інструкції, які виконуються під час імпорту, а не декларації. Що з цього випливає для порядку визначень і взаємних викликів функцій?
- [x] Чим `pass`, `...` (Ellipsis) і порожній блок відрізняються, і коли використовують кожен?
- [x] Коментарі `#`, docstrings `"""..."""` як перший вираз функції, і чому docstring це не коментар (`__doc__`, `help()`).
- [x] Як працює присвоєння: змінна це ім'я, прив'язане до об'єкта, а не комірка (до identity детально в m1-l03). Множинне присвоєння `a = b = 0`, розпакування `a, b = 1, 2`, обмін `a, b = b, a`. Чому `a = b = []` це пастка (один об'єкт).
- [x] Чи є в Python `const`, і як позначають константи насправді (конвенція, `Final` з typing, одне речення й посилання на m2-l06)?
- [x] Оператори, яких немає в JS або які інакші: `**`, `//`, `%` з від'ємними числами, `@`, ланцюжкові порівняння `0 < x < 10`, `and`/`or`/`not` словами, `in`, `is`. Що з `++`, `+=`, тернарного `x if c else y`?
- [x] Що робить `print` з кількома аргументами, `sep`, `end`, і як виглядає `input` (лише згадка: далі не використовується).
- [x] Які JS-звички треба свідомо прибрати в перший тиждень: `;` в кінці рядків, `{}` для блоків, camelCase, `===`, `!x` замість `not x`, `null`, `true`/`false` з малої.
