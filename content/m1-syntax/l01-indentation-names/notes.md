# Нотатки до m1-l01

## Що запускалось

Усе через `.venv/bin/python` (Python 3.12.12) з кореня проєкту; JS-твердження з `ts`-блоків через `node` v24.9.0.
Тимчасові скрипти лежали в scratch-директорії сесії й видалені після перевірки.

- Скрипт-перевірка `lesson.md`: витягує кожен python-блок верхнього рівня, записує його як `main.py`, запускає
  й порівнює stdout+stderr з наступним `text`-блоком після нормалізації (rstrip рядків). Результат: 53 блоки
  збіглися, 0 розбіжностей. Тому всі traceback-и в уроці мають ім'я файлу `main.py` і реальні номери рядків.
- Вручну, бо потребують кількох файлів, stdin або прапорця: пара `helpers.py` + `main.py` для `from m import *`
  (номер рядка в traceback враховує коментар `# main.py`), `input()` з `echo Ada |`, `python -OO main.py`
  для docstring, приклад з `help()`.
- Фрагменти з розділу "Типові помилки" зібрано в один скрипт і запущено; `print(null)` і реєстр до `def`
  перевірено окремо.
- TabError-приклад містить справжній символ табуляції в рядку 3 блоку; саме цей блок з файлу дає `TabError`.
- `ts`-блоки з виводом у коментарях (hoisting `greet`, дубль `label`, `-7 % 3`, `Math.trunc`,
  `-2 ** 2`, `0 < x < 10`, деструктуризація з зайвим елементом, `push` через alias) перевірено в node.
- `tasks.yaml`: розпарсено `yaml.safe_load`; кожне `solution + harness` виконано й звірено з `expected`;
  кожен `starter + harness` теж запущено, щоб переконатися, що стартовий код не проходить перевірку
  (t2 зі старим `errors = warnings = []` дає два однакові списки, t3 падає з `NameError: renderText`).
  Код з кожного quiz виконано, вивід збігається з варіантом `answer`. Перевірено, що кожен id вставлено
  в урок рівно один раз.

Не запускалось: ruff (у `.venv` його немає, завантаження через `uvx` не робилось). Твердження про правила
E703, F811 і набір `N` (pep8-naming, за замовчуванням вимкнений) подано без виводу лінтера. F811 сформульовано
обережно: правило спрацьовує лише на перевизначення невикористаної функції, тому на прикладі з уроку мовчить.
`Final` показано лише з боку runtime (переприсвоєння працює); вивід mypy/pyright не наводиться, бо їх у
`.venv` немає, детально в m2-l06 і m2-l08.

## Рішення

- Теоретичних розділів `##` сім, плюс `Для капстоуну` і три обов'язкові. Три підтеми винесено в `###`
  (порожній блок, коментарі й docstring, константи), щоб не роздувати сайдбар.
- Теорії 45 абзаців без callout-блоків (їх 9) і без списку типових помилок, тобто вище за орієнтир 20–40, але
  нижче за межу 50. Причина: `questions.md` ставить 12 питань, кожне з кодом і виводом, а більшість абзаців
  це одно-двореченнєві вступи до коротких прикладів. Якщо урок буде задовгим на практиці, природний поділ:
  "форма коду" (відступи, переноси, коментарі, імена, print) і "імена й значення" (присвоєння, зверху вниз,
  оператори). Зараз урок зданий цілим.
- Перетини з сусідами вирішено посиланнями: `//` і `%` на від'ємних числах дано одним прикладом форми
  оператора, числова сторона в m1-l02. Редакторська правка: тотожність `a == (a // b) * b + a % b`, циклічний
  індекс і `-(-a // b)` прибрано з цього уроку разом з live-блоком, бо m1-l02 розбирає їх повністю; лишився один
  рядок `print(-7 // 2, -7 % 3)` у парі з `Math.trunc(-7 / 2), -7 % 3` і посилання. Змінені блоки перепрогнано:
  Python дає `-4 2`, node `-3 -1`; ланцюжкові порівняння, `and`/`or`, `is` одним прикладом кожне з
  посиланням на m1-l03; тернарний оператор і walrus лише згадано з посиланням на m1-l05; `UnboundLocalError`
  показано як єдину схожість з hoisting, механізм LEGB у m1-l08; момент обчислення default одним прикладом,
  детально в m1-l07; стиль docstring у m1-l07; `Final` одним реченням з посиланням на m2-l06.
- Name mangling і `_x` показано на мінімальному класі з `__init__`, бо питання цього вимагає; класи як тема
  в m4-l01, dunder-методи в m4-l02.
- Приклад з `dis` для обміну `a, b = b, a` подано як "Під капотом", не live: вивід байткоду специфічний
  для 3.12.
- Завдань з кодом 5, усі `runtime: browser`, stdlib only, детерміновані. t3 перевіряє модуль, а не одну функцію
  (виняток зі спеки для уроків про синтаксис верхнього рівня): виправити імена за PEP 8 і порядок визначень.
  t1 перевіряє вивід `print`, тож харнес друкує й результат `None`. t5 використовує `enumerate`, `dict.items()`,
  `isupper`, `startswith`, які формально з m1-l04 і m1-l06; підказки дають їх прямо, учень senior.
- Проєктного завдання немає: репозиторій капстоуну з'являється в модулі 2. Розділ `Для капстоуну` прив'язаний
  до camelCase-контрактів FormBuilder і реєстру рендерерів; t5 це перекладач ключів, який у m2-l09 замінить
  `alias_generator`.
