# Ключові питання уроку m1-l02 "Типи: int без переповнення, None замість null і undefined"

Урок готовий, коли на кожне питання є відповідь з кодом і виводом.

- [x] Які базові типи є в Python (`int`, `float`, `str`, `bool`, `None`, `complex` лише згадати) і як дізнатись тип (`type`, `isinstance`). Чому `type(x) == int` гірше за `isinstance(x, int)`?
- [x] Чим `int` у Python відрізняється від `number` у JS: довільна точність (`2**100`), немає `MAX_SAFE_INTEGER`, немає окремого `BigInt`. Що таке `float` і що з `0.1 + 0.2`, `float("inf")`, `nan`, і чому `nan != nan`? Коли `Decimal` і `Fraction` (одне речення).
- [x] Ділення: `/` завжди дає float, `//` цілочисельне з округленням вниз (не до нуля, як `Math.trunc`), `%` зі знаком дільника (на відміну від JS), `divmod`, `round` з банківським округленням (`round(2.5) == 2`). Показати на від'ємних числах.
- [x] `bool` це підклас `int`: `True + True == 2`, `isinstance(True, int)`. Чому так і де це може здивувати (сума булів, `True in [1]`).
- [x] `None`: один об'єкт, тип `NoneType`, порівнюють через `is None`, функція без `return` повертає `None`. Чому Python обійшовся одним "нічого" там, де JS має `null` і `undefined`, і як JS-звички `?? ` і `?.` перекладаються (`x if x is not None else y`, `getattr`, `dict.get`).
- [x] Перетворення типів: `int("42")`, `int("42.0")` падає, `int(3.9)` відкидає дробову, `float("1e3")`, `str(42)`, `bool([])`. Чому немає неявного приведення `"1" + 1` (`TypeError`) і чому `"1" * 3` працює. Порівняти з коерцією JS.
- [x] Рядок у Python це не масив символів: немає типу `char`, `s[0]` це рядок довжини 1; `len` рахує code points, а не байти. Різниця `str` і `bytes` (одне речення, детально в m1-l04).
- [x] Незмінність: `int`, `float`, `str`, `bool`, `tuple` незмінні, `list`, `dict`, `set` змінні. Що це означає для `+=` на числі й на списку (різні об'єкти чи той самий; `id`). Повна картина в m2-l02, тут лише ідея.
- [x] Анотації типів як документація: `x: int = 5`, `def f(a: str) -> bool`. Чому інтерпретатор їх не перевіряє (`x: int = "a"` працює), і чим це відрізняється від TS. Детально в m2-l06, тут одне речення й звичка писати анотації з першого дня.
- [x] Що робить `type()` з класами і що таке "усе є об'єкт": `(1).bit_length()`, `int.__name__`, `type(int)`. Лише дотик, без метакласів.
- [x] Які JS-інтуїції тут підводять: `0.1 + 0.2 == 0.3` однаково `False`, але `9007199254740993` у Python точний; `typeof null === "object"` не має аналога; `NaN` лише з float; `"5" * 2` не `10`.
