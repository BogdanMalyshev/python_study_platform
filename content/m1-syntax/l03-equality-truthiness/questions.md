# Ключові питання уроку m1-l03 "== проти is, truthiness"

Урок готовий, коли на кожне питання є відповідь з кодом і виводом.

- [x] Що порівнює `==` (значення, через `__eq__`) і що порівнює `is` (identity, той самий об'єкт, `id()`). Чому в Python немає `===` і чому `==` тут не має коерції між типами (`1 == "1"` це `False`, а не `true` як у JS з `==`).
- [x] Коли `is` правильний: `is None`, `is True`/`is False` у рідкісних випадках, sentinel-об'єкти. Чому `x == None` працює, але вважається помилкою (PEP 8, перевизначений `__eq__`).
- [x] Чому `a = 256; b = 256; a is b` дає `True`, а з `257` може дати `False`: кешування малих int, інтернування рядків. Чому це деталь реалізації CPython і на неї не можна спиратись. `SyntaxWarning` на `x is 5` у 3.8+.
- [x] Як `==` працює для списків, кортежів, словників, множин: поелементно, рекурсивно, незалежно від identity. Порівняти з JS, де `[1] == [1]` це `false`. Що з `[1, 2] == (1, 2)`?
- [x] Що таке truthiness у Python: що хибне (`None`, `False`, `0`, `0.0`, `""`, `[]`, `{}`, `set()`, `()`, `range(0)`), і чому. Чим це відрізняється від JS: порожній масив і об'єкт у JS істинні, у Python хибні. `"0"` істинний в обох.
- [x] Як об'єкт вирішує свою truthiness: `__bool__`, потім `__len__`, інакше `True`. Показати на власному класі.
- [x] `and` і `or` повертають операнд, а не bool: `x or default`, `a and b`. Чим `x or default` відрізняється від `??` у JS (ловить усі falsy, не лише None) і коли це баг (`count or 10` при `count == 0`). Правильна заміна: `x if x is not None else default`.
- [x] Ланцюжкові порівняння `0 <= x < 10` і чому `a < b < c` це не `(a < b) < c`. Пастка `x == 1 or 2` (завжди істинне) і `x in (1, 2)` як правильна форма.
- [x] `not` як слово, `!=`, пріоритет `not` / `and` / `or`, і де потрібні дужки.
- [x] Порівняння різних типів: `1 < "a"` це `TypeError`, а не `false`; `1 == 1.0` це `True`; `True == 1`. Сортування змішаного списку падає.
- [x] Перевірка на порожнечу: ідіома `if not items:` замість `if len(items) == 0`, і чому для `None`-чутливих місць треба `is None` окремо від truthiness.
- [x] Які JS-звички тут шкодять: `=== `, `!== null && !== undefined`, `if (arr.length)`, `||` для дефолтів, `Boolean(x)` замість `bool(x)`.
