# Ключові питання уроку m1-l06 "Цикли: for ітерує значення, а не індекси"

Урок готовий, коли на кожне питання є відповідь з кодом і виводом.

- [x] Чому в Python `for` не має лічильника й умови, і що він насправді робить з об'єктом праворуч від `in`? Що таке iterable з погляду `for` (на рівні ідеї, без деталей протоколу: протокол детально в m5-l01)?
- [x] Як отримати індекс разом зі значенням і чому `range(len(x))` вважається поганим стилем? Що робить `enumerate(x, start=1)`?
- [x] Як ітерувати дві й більше послідовностей одночасно, що робить `zip` з різною довжиною і що змінює `strict=True`?
- [x] Чи створює `for` новий scope для змінної циклу і що це означає для коду після циклу? Чим це відрізняється від `for (let i ...)` у JS?
- [x] Що робить `range`: це список чи ні, чи можна його пройти двічі, скільки пам'яті займає `range(10**9)`, як працюють `start`, `stop`, `step` і від'ємний крок?
- [x] Коли використовувати `while`, і як виглядає ідіоматична заміна `do...while`, якого в Python немає?
- [x] Що робить `else` у `for` і `while`, коли він виконується, а коли ні, і для якої задачі він корисний (пошук без прапорця)?
- [x] Як ітерувати словник: ключі, значення, пари; у якому порядку; що станеться при зміні розміру словника під час ітерації?
- [x] Що станеться при видаленні елементів зі списку під час ітерації по ньому і як робити правильно?
- [x] Чим `for...in` у JS відрізняється від `for ... in` у Python, і які звички з `for...of`, `.forEach`, `.map` переносяться, а які ні?
- [x] Коли цикл варто замінити на comprehension або на `any` / `all` / `sum` з генераторним виразом, а коли ні (comprehensions детально в m1-l10, тут лише межа)?
- [x] Як вийти з вкладених циклів: `break` виходить лише з внутрішнього, які є ідіоматичні способи (функція з `return`, прапорець, `for-else`, `itertools.product`)?
- [x] Чому замикання, створені в циклі, бачать останнє значення змінної (пізнє зв'язування), і як це виправити (`lambda i=i:`, `functools.partial`)? Чим це відрізняється від поведінки `let` у JS?
