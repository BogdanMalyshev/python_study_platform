# Ключові питання уроку m2-l03 "Зрізи, розпакування, *rest"

Урок готовий, коли на кожне питання є відповідь з кодом і виводом.

- [x] Зрізи `seq[start:stop:step]` для list, tuple, str, range, bytes: `stop` не включно, від'ємні індекси, пропущені межі, `[::-1]`, `[::2]`. Зріз ніколи не кидає за межами, індекс кидає. Порівняти з `slice`, `at`, і відсутністю step у JS.
- [x] Зріз це копія (для list) або новий об'єкт, а не view: зміна зрізу не змінює оригінал. Виняток: `memoryview` і NumPy, одне речення.
- [x] Присвоєння в зріз: `lst[1:3] = [9, 9, 9]` змінює довжину, `lst[:] = []` очищає на місці (і чому це відрізняється від `lst = []` при aliasing), `del lst[::2]`. Аналог `splice`.
- [x] Об'єкт `slice`: `slice(1, 3)`, `s.indices(len)`, навіщо (іменовані зрізи `NAME = slice(0, 10)`, передача зрізу як параметра). Як `__getitem__` отримує `slice` (одне речення, детально в m4-l02).
- [x] Розпакування: `a, b = pair`, `a, b, c = "xyz"`, вкладене `(a, b), c = ...`, обмін `a, b = b, a`, і `ValueError: too many values to unpack`. Чому дужки не обов'язкові.
- [x] Зірочка в розпакуванні: `first, *rest = items`, `*init, last = items`, `a, *mid, b = items`, порожній `rest` як `[]`. Аналог rest у деструктуризації, але `*` може бути посередині.
- [x] Зірочка при виклику й у літералах: `f(*args)`, `[*a, *b]`, `{**d1, **d2}`, `(*a, *b)`. Аналог spread. Обмеження: одна `*` у присвоєнні, скільки завгодно у виклику.
- [x] Розпакування словника: `**` лише для виклику й літералів; для ключів `k, v = item` в циклі по `items()`; `dict(zip(...))`. Чому немає `{a, b} = obj` і як замінити (`a, b = d["a"], d["b"]`, `operator.itemgetter("a", "b")(d)`).
- [x] Ігнорування значень: `_`, `*_`, `first, *_ = items`, і конвенція `_` у REPL (конфлікт).
- [x] Розпакування в циклі: `for i, (name, value) in enumerate(pairs)` (посилання на m1-l06), у comprehension, у `match` (посилання на m1-l05).
- [x] Для капстоуну: розбити список елементів на перший екран і решту (`head, *tail`), злити тему й overrides (`{**theme, **element["style"]}`), пагінація елементів через зрізи `elements[i:i + page_size]`.
- [x] Які JS-звички тут заважають: `arr.slice(-1)[0]` замість `arr[-1]`, `const {a, b} = obj`, `[a, ...rest]` лише на початку, `Object.assign` замість `{**a, **b}`, очікування, що `slice` з step не існує.
